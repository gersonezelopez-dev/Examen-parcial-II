# Examen Parcial II - Estacionamiento 


Aplicación de consola en Java para registrar y administrar vehículos de un estacionamiento, con apoyo en pgAdmin4 SQL.

## Funciones principales

- Registrar automóviles y motocicletas.
- Evitar placas duplicadas.
- Buscar vehículos por placa.
- Calcular el costo según las horas utilizadas.
- Aplicar descuento del 10% si supera 5 horas.
- Mostrar el vehículo con mayor costo.
- Mostrar total general y total por tipo.

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos
- ArrayList
- HashSet
- HashMap
- Manejo de excepciones
- PostgreSQL
- SQL
